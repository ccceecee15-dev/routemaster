==================================================
2. DO NOT MISINTERPRET MERCHANDISE AREA
==================================================

This is important.

Merchandise Area describes the merchandise being routed.

It does NOT describe the store.

A single store can have multiple Merchandise Areas.

For example:

Store 101 can have:

- Snacks → McLane → Warehouse BULK → Monday
- Energy Drinks → Red Bull → DSD → Tuesday
- Beverages → Vendor X → DSD → Thursday

Therefore the UI must allow multiple route/order assignments for the same store.

Do not collapse these into one store-level route.
