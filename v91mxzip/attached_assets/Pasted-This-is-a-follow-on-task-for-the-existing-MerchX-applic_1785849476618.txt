Objective

Add a new screen called Route Master under the existing Master Data section.

This screen replaces the Excel spreadsheet currently used by planners to maintain Warehouse-to-Store routing information.

The purpose of this screen is to allow users to view and maintain routing relationships and warehouse lead times that are used throughout Delivery Points, Warehouse Demand calculations and Replenishment planning.

This is Master Data maintenance, not a planning screen.

The UI should feel very familiar to users who currently work in Excel while remaining fully consistent with the existing MerchX application.
